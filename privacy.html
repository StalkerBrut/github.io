Политика конфиденциальности ZTALIN YouTube Agent

Дата вступления в силу: 21 ноября 2026 г.

1. Кто использует приложение

ZTALIN YouTube Agent — личное некоммерческое приложение, которым пользуется только автор канала ZTALIN на собственном компьютере. Приложение не предоставляется третьим лицам.

2. Какие данные запрашиваются

После согласия владельца аккаунта через Google OAuth приложение получает доступ только на чтение:

  • youtube.readonly — сведения о собственном канале и его роликах;
  • yt-analytics.readonly — аналитика собственного канала.

Приложение не получает и не хранит пароль Google.

3. Как данные используются

Данные используются только для отображения статистики и аналитики канала его владельцу и для планирования роликов. Приложение не публикует, не изменяет и не удаляет видео, комментарии или настройки канала.

4. Хранение и передача

Все данные и токены доступа хранятся только на компьютере владельца; токены зашифрованы средствами операционной системы. Данные не передаются, не продаются и не раскрываются третьим лицам и не используются для рекламы. Использование данных, полученных от Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

5. Удаление данных и отзыв доступа

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions или кнопкой «Отключить канал» в приложении. Локальные данные удаляются вместе с папкой приложения.

6. Изменения

Изменения этой политики публикуются на этой странице.

Privacy Policy (English)

ZTALIN YouTube Agent is a personal, non-commercial tool used only by the owner of the ZTALIN YouTube channel on their own computer. With the account owner's consent via Google OAuth it requests read-only access (youtube.readonly, yt-analytics.readonly) to the owner's own channel data and analytics. It never receives or stores Google passwords and never uploads, modifies or deletes any content.

All data and access tokens are stored only on the owner's computer (tokens are encrypted by the operating system). Data is not shared, sold or disclosed to third parties and is not used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at myaccount.google.com/permissions.
